## 🚀 Getting Started

Follow these steps to run the Java programs locally.

### 1. Clone the Repository

```bash
git clone https://github.com/subhasish20/Java_Programming.git
cd Java_Programming
```

### 2. Install and Configure the JDK

Make sure Java Development Kit (JDK) is installed.

```bash
java -version
javac -version
```

If not installed, download the latest JDK from the official Oracle or OpenJDK website.

### 3. Compile a Java Program

Navigate to the folder containing the `.java` file and compile it:

```bash
javac HelloWorld.java
```

### 4. Run the Java Program

```bash
java HelloWorld
```

You can also open the repository in an IDE such as IntelliJ IDEA, Eclipse, or VS Code and run the programs directly.
